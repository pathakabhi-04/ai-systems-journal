# Foundations

Small exercises. One folder each, each with a README saying what it does and how to run it.

Planned:

- `fastapi-serve/` — a trained model behind a POST endpoint with proper request/response models
- `gradio-demo/` — the same model with a UI, deployed to Hugging Face Spaces
- `tool-calling/` — structured outputs and a function the model can actually invoke
- `prompt-caching/` — measure a repeated-prefix workload before and after
- `eval-harness/` — build an eval set, score prompt variants against it
- `agent-loop/` — plan, act, observe, written from scratch before touching any framework
- `cost-logging/` — tokens, cost and latency per pipeline stage

Rule: nothing gets ticked off until it runs and I could explain it to someone else.
